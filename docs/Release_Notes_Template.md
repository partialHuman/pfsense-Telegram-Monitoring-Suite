#  Release v1.0.0

Release Date: 2026-07-31

---

# Overview

Welcome to **v1.0.0** of the **pfSense Telegram Monitoring Suite**.

This release introduces a modular monitoring framework for pfSense with Telegram-based notifications, WireGuard monitoring, Suricata integration, and automated reporting.
